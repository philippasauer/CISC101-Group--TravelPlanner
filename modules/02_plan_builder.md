### **Module 2 — Plan Builder (Options → Days)**
Create a short list of candidate activities (e.g., attractions, restaurants, parks).  
Each activity includes type, estimated duration, **per-person cost range**, and **distance/time tier**.

### **Activity Metadata Standards**
- **Proximity tiers (transfer time between activities):**
  - **Near lodging / morning start:** ≤15 min walk or ≤20 min transit.  
  - **Close by (midday):** ≤15 min transfer from morning activity.  
  - **General transfers:** Aim ≤15 min, cap ≤25 min. If exceeded, mark optional with a short reason.  

- **Duration bands:**
  - **Short:** 45–90 minutes  
  - **Medium:** 2–3 hours  
  - **Long:** 3–5 hours  
  - Use flexible windows for outdoor sights; fixed slots for ticketed events.  

- **Per-person budget ranges (normalized):**
  - **Affordable:** <$20 per person (meals or entry)  
  - **Mid-range:** $20–60 per person  
  - **Luxury:** $60+ per person  
  - Meals: food-only, per person; note if service/tax expected.  
  - Activities: per person, excluding transport unless integral.  

### **Day Plan Loop**
For each day:  
- **Morning:** Pick a short or medium activity within “near lodging” tier.  
- **Midday:** Select a nearby attraction ≤15 min transfer; include lunch with compliant options in the same area.  
- **Afternoon:** Choose a different theme aligned to user interests; keep transfer ≤25 min; add one indoor backup.  
- **Evening:**  
  - Restaurant in-budget with dietary compliance.  
  - If an event is chosen (show, tour, concert), **anchor its fixed start time** and adjust prior slots to prevent overlap. Afternoon activity may be shortened or relocated to ensure natural pacing.  

### **Additional Rules**
- **Theme diversity:** Afternoon should differ from morning/midday, weighted toward user interests (e.g., culture, food, nature).  
- **Transfers:** Prefer walking if ≤15 min and mobility allows; otherwise one-hop transit or rideshare. Avoid multi-hop chains unless essential.  
- **Dietary needs:** Prefer venues with clearly labeled vegan/gluten-free menus offering ≥2 compliant dishes. If uncertain, flag “check menu” and provide a compliant alternate.  
- **Alternates:** Pre-generate one indoor backup per day in the same slot and neighborhood for easy Weather Swap.  
- **Event timing:** Fixed-start evening events override flexible pacing; earlier activities must be trimmed or shifted to avoid impossible schedules.
